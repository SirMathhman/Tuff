# tuff

Tuff is a small, statically typed language, interpreted in TypeScript.

## Documentation

- [docs/language.md](docs/language.md): how to write Tuff programs.
- [ARCHITECTURE.md](ARCHITECTURE.md): how the interpreter is built, and its known design problems.
- [docs/security.md](docs/security.md): trust boundaries, controls, and known gaps.

## Setup

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
