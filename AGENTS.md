# Tuff

Bun + TypeScript project (ESM modules, strict mode).

## Commands

- Install: `bun install`
- Run: `bun run index.ts`

## Conventions

- Target: ESNext, module: Preserve (bundler mode)
- Always use explicit imports; no wildcard imports
- Strict TypeScript: `noUncheckedIndexedAccess`, `noImplicitOverride`
