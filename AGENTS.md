# Tuff

Bun + TypeScript project (ESNext modules, strict mode). See [README.md](README.md) for setup and run commands.

## Commands
- Install: `bun install`
- Run: `bun run index.ts`

## Conventions
- TypeScript: strict, ESNext target, bundler module resolution, verbatim module syntax.
- No build step — Bun runs TypeScript directly.
